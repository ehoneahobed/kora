# Kora.js 1.0.0-beta.12

Beta.12 hardens authenticated scoped sync and application recovery:

- Delivery stalls now require an actual sent, unacknowledged range; acknowledged idle sessions and
  out-of-scope tails do not emit false diagnostics.
- Collections are collision-free under `app.collections`, compatible direct accessors remain for
  non-reserved names, and `app.on()` always subscribes to framework events.
- `AuthBoundKoraProvider` supports classified application error UI and serialized, resource-safe retry.
- Opt-in `scopeExit: 'retract'` removes records from only the client view and quarantines pending writes.
- Auth providers can return separate `downlinkScopes` and `uplinkScopes`; `scopes` remains shorthand.
- Permanent uplink scope violations are durably rejected and acknowledged instead of pinning the
  queue; later writes continue, transient rejections use bounded exponential backoff, and ingest
  metrics separate batches, newly materialized operations, duplicates, and rejections.

Run `pnpm test:pre-release`, inspect `pnpm release:dry-run`, publish with the `beta` dist-tag, verify
all registry versions, then tag the release commit as `v1.0.0-beta.12`.
